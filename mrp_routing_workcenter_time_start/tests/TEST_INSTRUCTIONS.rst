Setup Time:

- Go to Manufacturing > Products > Bills of Materials
- Create or open new BoM for "Product 1" with components "Product 1.1" and "Product 1.2"
- Open "Operations" Tab
- Create and add operations
- Define Setup Time for every operation

Manufacturing Order:

- Go to Manufacturing > Operations > Manufacturing Orders
- Create new order for "Product 1"
- Click on "Overview" button
- Confirm that setup time is added to operation times
